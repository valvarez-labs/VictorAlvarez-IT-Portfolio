Anàlisi del Fitxer XML

Guia didàctica sobre l'estructura de biblioteca.xml

1. El Pròleg (Declaració XML)

Tot fitxer XML comença amb aquesta línia. Indica la versió de l'estàndard i la codificació de caràcters.

<?xml version="1.0" encoding="UTF-8"?>

L'ús de UTF-8 és fonamental per permetre accents i caràcters especials (com la "ó" de Zafón).

2. L'Element Arrel

Un document XML ha de tenir exactament un element que contingui tota la resta. En el nostre exercici és <biblioteca>.

<biblioteca xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"> <!-- Aquí van tots els llibres --> </biblioteca>

L'atribut xmlns:xsi defineix un espai de noms per a instàncies d'esquemes XML.

3. Elements i Atributs

L'enunciat demanava que l'ISBN fos un atribut i la resta d'informació fossin elements fills:

  • Atribut (isbn): Es col·loca dins de l'etiqueta d'obertura. Serveix per identificar el llibre de manera única.
  • Elements fills: Són dades que es troben entre les etiquetes d'obertura i tancament.
<llibre isbn="978-84-376-0494-7"> <titol>La sombra del viento</titol> <autor>Carlos Ruiz Zafón</autor> <any>2001</any> <preu>19.95</preu> </llibre>

4. Glossari d'Etiquetes

titol El nom oficial de l'obra.
autor Qui ha escrit el llibre.
any L'any de la primera publicació.
preu El cost monetari (format decimal amb punt).

5. Visualització del Codi Complet

Seguint l'enunciat, hem creat 3 blocs <llibre> per complir amb el mínim demanat:

<?xml version="1.0" encoding="UTF-8"?> <biblioteca> <llibre isbn="...">...</llibre> <llibre isbn="...">...</llibre> <llibre isbn="...">...</llibre> </biblioteca>
