Correcció d'Errors XML

Exercici 2: Identificació i depuració de sintaxi

CODI AMB ERRORS: 
<alumnes>
  <alumne id=1>
    <nom>Pepet
    <nota>7,5</nota>
  </alumne>
  <curs>DAW</alumne>
</alumnes>
CODI CORREGIT: 
<alumnes>
  <alumne id="1">
    <nom>Pepet</nom>
    <nota>7.5</nota>
    <curs>DAW</curs>
  </alumne>
</alumnes>

Anàlisi dels errors detectats

1. Atributs sense cometes

A l'etiqueta <alumne id=1>, el valor de l'atribut ha d'anar sempre entre cometes: id="1".

2. Etiquetes sense tancament

L'etiqueta <nom> no es tancava. En XML, cada etiqueta d'obertura ha de tenir la seva corresponent de tancament: <nom>Pepet</nom>.

3. Separador decimal incorrecte

En informàtica i XML, s'utilitza el punt (.) i no la coma per als valors decimals: 7.5.

4. Estructura jeràrquica (Nesting)

L'etiqueta <curs> estava mal tancada amb </alumne> i es trobava fora de l'estructura de l'estudiant. S'ha de tancar correctament i moure a l'interior de l'alumne perquè les dades estiguin ben agrupades.

Conclusió

Un document XML és "ben format" només quan compleix estrictament totes les regles de sintaxi (cometes, tancament d'etiquetes i jerarquia). A diferència de l'HTML, l'XML no perdona cap error i el navegador o l'analitzador deixaria de processar-lo.
