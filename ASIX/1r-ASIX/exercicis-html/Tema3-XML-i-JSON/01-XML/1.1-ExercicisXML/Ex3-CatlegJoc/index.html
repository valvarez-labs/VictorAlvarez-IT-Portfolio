Gestió de Caràcters Especials

Exercici 3: Ús de seccions CDATA en un catàleg de jocs

El problema: Caràcters prohibits

En XML, certs caràcters estan reservats perquè serveixen per definir l'estructura. Si els usem dins d'un text normal, el fitxer donarà error:

  • < (menys que): Es confon amb l'inici d'una etiqueta.
  • & (ampersand): S'usa per iniciar entitats.
  • > (més que): Es confon amb el final d'una etiqueta.

La Solució: Secció CDATA

La instrucció <![CDATA[ ... ]]> indica a l'analitzador XML que tot el que hi ha dins és text pla i no ha d'intentar interpretar-lo com a codi.

<joc id="4" plataforma="PC"> <titol>Minecraft</titol> <descripcio><![CDATA[Joc d'exploració & construcció on pots crear <mons>]]></descripcio> </joc>

Alternativa: Entitats Predefinides

Si no vols usar CDATA, hauries de substituir cada caràcter un per un:

Caràcter Entitat XML Exemple
& &amp; Exploració &amp; construcció
< &lt; &lt;mons&gt;
> &gt; Resultat &gt; 10

Per què hem triat CDATA aquí?

En la resposta de l'exercici hem afegit el quart joc (Minecraft) fent servir CDATA perquè és molt més llegible quan tenim frases llargues amb molts símbols tècnics. Ens permet escriure <mons> de forma natural sense que el sistema pensi que "mons" és una etiqueta XML real.
