Modelatge de Dades Complex

Exercici 4: Estructura de videojoc i nivells anidats

1. L'Element Arrel amb múltiples atributs

A diferència dels exercicis anteriors, aquí l'element arrel <joc> conté dues dades clau com a atributs:

<joc nom="Dark Adventure" plataforma="PC">

Aquesta és una manera eficient d'etiquetar l'objecte principal abans de descriure els seus detalls interiors.

2. Estructura de col·lecció (Anidament)

Dins de <joc>, tenim diversos elements repetitius <nivell>. Cada nivell funciona com un objecte independent que conté la seva pròpia informació:

<nivell numero="1"> <nom>Bosc Inicial</nom> <numeroEnemics>10</numeroEnemics> <puntsMaxims>1000</puntsMaxims> <completat>true</completat> </nivell>

3. Tipus de dades utilitzats

Atributs Identificadors L'atribut numero="1" serveix per indexar de forma ràpida sense entrar en el contingut.
Valors Booleans L'etiqueta <completat> fa servir true o false, ideal per a lògica de programació.
Valors Numèrics numeroEnemics i puntsMaxims contenen dades quantitatives per a càlculs posteriors.
