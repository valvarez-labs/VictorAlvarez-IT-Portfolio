# Cómo añadir nuevas actividades de ASIX

Estructura: `ASIX/2n-ASIX/<modulo>/<tema o RA>/<actividad>/`

1. Copiar la actividad dentro de su módulo (nombres sin espacios ni tildes, separados por `-`).
2. Regenerar el README del módulo y actualizar el contador en `ASIX/README.md`.
3. Una sola actividad o tema por commit, con mensaje del tipo: `ASIX 2n: añade 0378 Tema 2 - Actividad VPN`.
4. Antes de publicar: no incluir contraseñas, claves, datos personales, imágenes de disco ni ficheros de más de 50 MB.

No se reorganiza el contenido existente; solo se añaden carpetas y se actualizan los índices.
